# Entenda o Algoritmo: Por Que as Redes Sociais Viciam

> 🚧 Site em andamento: as videoaulas estão sendo finalizadas.

Site do curso **“Entenda o Algoritmo: Por Que as Redes Sociais Viciam”**, voltado a crianças e adolescentes, por serem os principais usuários das redes sociais e, consequentemente, os mais afetados pelo uso excessivo dessas plataformas.

O objetivo do projeto é promover a conscientização sobre o funcionamento dos algoritmos e o uso consciente da tecnologia.

Curso gratuito e **sem fins lucrativos**, desenvolvido como Atividade Extensionista do curso de Engenharia de Software.

🔗 **Acesse o site:** https://atividade-extensionista-iota.vercel.app/

## Conteúdo do curso

| Vídeo | Tema |
| --- | --- |
| Introdução | Boas-vindas ao curso |
| Aula 1 | Caixa de Skinner |
| Aula 2 | Algoritmo de redes sociais |
| Aula 3 | Lados positivos e negativos das redes sociais |
| Aula 4 | A importância de ter hobbies e se exercitar para nossa mente |
| Encerramento | Encerramento do curso |

## Páginas do site

- **Início** (`index.html`): apresentação do curso.
- **Acessar curso** (`curso.html`): rota de aprendizagem com os vídeos do curso.
- **Mais informações** (`mais-informacoes.html`): referências, vídeos utilizados, créditos das imagens e informações do projeto.

## Tecnologias

- **HTML5**: estrutura das páginas.
- **SCSS**: estilo e responsividade, organizado em arquivos parciais e compilado para CSS.
- **JavaScript**: menu do celular e troca dos vídeos na rota de aprendizagem.
- **Figma**: design das telas (desktop e celular).
- **GitHub** e **Vercel**: versionamento do código e hospedagem do site.

## Estrutura de pastas

```
├── index.html               # Início
├── curso.html               # Rota de aprendizagem
├── mais-informacoes.html    # Referências e créditos
├── img/                     # Imagens do site
├── js/
│   └── script.js            # Menu do celular e troca dos vídeos
└── index_sass/
    ├── style.sass           # Arquivo principal (importa os parciais)
    ├── _variaveis.scss      # Cores e fontes
    ├── _header.scss         # Cabeçalho e menu
    ├── _containers.scss     # Seções da página inicial
    ├── _footer.scss         # Rodapé
    ├── _paginas.scss        # Páginas do curso e de mais informações
    ├── style.css            # CSS compilado
    └── reset.css
```
